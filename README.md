# Blinkit-Project Dashboard
## Project Overview
This project analyzes Blinkit's sales data using Microsoft Excel. The dashboard provides insights into sales performance, product categories, outlet types, customer ratings, and revenue trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Data Analysis
5. Dashboard Creation
6. Insights Generation

## Key Metrics
- Total Sales
- Average Sales
- Number of Items
- Average Rating

## Dashboard Features
- Sales by Item Type
- Sales by Outlet Size
- Sales by Outlet Location
- Fat Content Analysis
- Outlet Establishment Trend
- Interactive Filters and Slicers

## Key Insights
- Identified top-performing product categories.
- Analyzed sales across different outlet locations.
- Compared performance by outlet size and type.
- Evaluated customer ratings and sales trends.
